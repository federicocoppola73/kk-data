# Content assets

Place only small, licensed or original assets here during the initial phase.

Suggested layout:
- `players/`
- `clubs/`
- `illustrations/`

Use stable asset IDs in content JSON. The app should resolve IDs through an asset manifest or backend service rather than constructing raw GitHub URLs.

Before adding an asset, record its source, licence, attribution and permission status in the corresponding content record. Do not add unlicensed player photos or club crests.
